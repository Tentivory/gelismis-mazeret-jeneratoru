# Gelişmiş Mazeret Üreticisi

## Dünyanın En İleri Teknoloji Bahanesi

Bu proje, insanlık tarihinin en büyük sorunlarından biri olan "geç kalma" problemine çözüm üretmek amacıyla (asla çözmeyecek) geliştirilmiştir. 

Bilimsel araştırmalar (benim tarafımdan uydurulmuş) göstermektedir ki, insanların %99.7'si geç kalır ve %0.3'ü de "zamanında geldim" diye yalan söyler. Bu yazılım, o %99.7'ye hizmet eder.

### Nasıl Çalışır?

1. Programı çalıştırırsınız.
2. Neden geç kaldığınızı söylersiniz (veya söylemezsiniz).
3. Program size öyle bir mazeret üretir ki, karşınızdaki kişi "vay be, gerçekten de" der (veya güler geçer).

### Kurulum

```bash
python mazeret_ureticisi.py
```

Hepsi bu. Bağımlılık yok. Hayat zaten yeterince karmaşık.

### Özellikler

- Tamamen Türkçe mazeretler
- Kuantum fiziği ve kedi referansları
- %87.3 başarı oranı (kaynak: hayal gücüm)
- Geç kalma sürenizi uzatmaz, sadece açıklamanızı güzelleştirir

### Uyarı

Bu programı kullanarak işinizden kovulursanız sorumluluk kabul etmiyoruz. Ama en azından güzel bir mazeretiniz olmuş olur.
